# GitHub Copilot Showcase

Examples of tasks that can be demonstrated live:

- Generate the initial React dashboard structure and dark SOC design system.
- Scaffold a FastAPI incident API with Pydantic validation and health checks.
- Create deterministic simulation data for the four incident scenarios.
- Write tests for decision consequences and score calculation.
- Refactor the repeated UI cards into reusable components.
- Document architecture, demo flow, and description of the AI fallback assistant.
- Debug event-stream filtering and timeline behavior during a live iteration.

These examples show how Copilot can help with UI generation, API scaffolding, test creation, and rapid technical iteration while keeping the product grounded in a clear architecture.
